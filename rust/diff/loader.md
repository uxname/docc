# loader: отличия Rust от Go

### 1. Слишком большое число в документе
Было: число вроде `1e999` (больше любого допустимого) Go превращал в «бесконечность» и в таком виде отдавал на проверку по схеме.
Стало: Rust подставляет самое большое обычное число с тем же знаком (около `1.8e308`). Для проверки по схеме оно ведёт себя так же: больше любого предела.
Почему: в формате значений, которым пользуется Rust-версия, «бесконечность» записать нельзя. В настоящих документах такие числа не встречаются.
