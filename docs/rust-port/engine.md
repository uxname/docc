# engine: отличия Rust от Go

### 1. «Битые» байты в именах файлов и в docc.lock показываются знаком «�»
Было: если в `docs/src` лежит файл или папка с именем не в UTF-8 (например, `a\xff.json`, созданный программой в старой кодировке), Go в текстовом отчёте печатал путь с исходным байтом: `docs/src/a\xff.json:1:1: error DOC104 ...`. Так же он печатал такие байты из строки `docc.lock` вида `index y%FF 12345678` в сообщении DOC503 `the link from index to y\xff no longer exists`. Картинку `![](x.png)` из документа в папке с таким именем Go находил.
Стало: Rust пишет на месте такого байта знак «�»: `docs/src/a�.json:1:1: error DOC104 ...`. Сам текст замечания тот же, что у Go (`file name "a\xff" is not a valid id`), отчёт в формате JSON совпадает с Go полностью (Go там тоже ставит «�»). Картинку рядом с документом в папке с «битым» именем Rust не находит и сообщает DOC213.
Почему: путь и текст замечания в Rust хранятся как текст, а «битые» байты текстом не записать. Такие имена и так ошибка (DOC104), а в настоящих проектах их не бывает.
