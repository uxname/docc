# cli: отличия Rust от Go

### 1. Версия у сборки без номера выпуска
Было: `docc --version` у программы, собранной обычной командой `go build` прямо в папке репозитория, показывал номер, который Go сам выводит из Git, например `docc v0.0.1-test.0.20261016234248-eea71c915bda`. Без Git (или с `-buildvcs=false`) — `docc dev`.
Стало: Rust берёт номер только из переменной `DOCC_VERSION` при сборке (`DOCC_VERSION=v0.1.0 cargo build --release`), без неё показывает `docc dev`. Выпуски, собранные скриптом выпуска с номером, показывают тот же номер, что и раньше.
Почему: Rust не узнаёт номер из Git сам. На такой сборке `docc update` отказывается работать, как и у сборки Go без Git; на выпуски это не влияет.

### 2. Аргументы командной строки не в UTF-8
Было: Go передавал такие байты как есть. Например, `docc comments done $'\xff'` писал `no comment "\xff" in docc.comments.json`, а `docc comments import $'\xff.json'` открывал файл с этим именем.
Стало: Rust заменяет такие байты знаком «�»: `no comment "�" in docc.comments.json`; файл, в имени которого есть такие байты, программа не найдёт. Раньше Rust в этом случае падал, теперь выдаёт обычную ошибку с кодом 2.
Почему: Rust хранит текст только в UTF-8. Имена файлов и аргументы не в UTF-8 на Linux и macOS почти не встречаются.

### 3. Папка, открытая через символическую ссылку
Было: Go искал docc.json, поднимаясь по пути, который видит пользователь (переменная `PWD`, через ссылку). Пример: `/a/docc.json`, `/a/link` — ссылка на `/real/sub`, `/real/docc.json`. `cd /a/link && docc validate` брал `/a/docc.json`.
Стало: Rust поднимается по настоящему пути на диске (`/real/sub` → `/real`) и берёт `/real/docc.json`.
Почему: так же, по настоящему пути, разбирает пути модуль настроек (config), перенесённый раньше. Если поиск шёл бы по одному пути, а чтение по другому, Rust прочитал бы не тот файл, который нашёл. Без символических ссылок поведение одинаковое.

### 4. Текст сетевых ошибок в `docc update`
Было: `docc: error: cannot read the release list: Get "http://127.0.0.1:1/latest/download/checksums.txt": dial tcp 127.0.0.1:1: connect: connection refused`
Стало: `docc: error: cannot read the release list: io: Connection refused (os error 111)`
Почему: эту часть сообщения пишет сетевая библиотека (в Go — встроенная, в Rust — ureq). Начало сообщения и код выхода 2 те же. Ответ сервера с ошибкой выглядит одинаково: `<адрес>: 404 Not Found`.
